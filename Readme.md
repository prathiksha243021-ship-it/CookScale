CookScale: Recipe Scaling and Smart Grocery Planner

Team

[Prathiksha HN] ([1AT24CS157]), [Rakshita] ([1AT24CS168]), Java Track

How to run

javac Main.java
java Main

Features that work

1. Add Recipe – Add new recipes with their ingredients and quantities.
2. View Recipes – Display the available recipes.
3. Scale Recipe – Adjust ingredient quantities according to the required servings.
4. Generate Grocery List – Generate a grocery list based on recipe ingredients.
5. Manage Grocery List – Manage the generated grocery items.
6. File Handling – Save recipes and load previously saved recipes automatically.
